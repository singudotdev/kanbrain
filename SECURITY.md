# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/singudotdev/kanbrain/security/advisories/new), with the
version (`kb --version`), your platform, and the steps that show the problem.

## Supported versions

Only the latest release gets fixes. Upgrade with `kb update`, or the kanban app's **Update** (see
[Getting started](docs/getting-started.md#updating)).
