Brains carry a data format version and migrate from older ones; the kanban app offers newer releases and installs
them; no update, from the app or `kb update`, runs while an agent has a task in doing.

- Data format (`core/src/migrate.rs`): `FORMAT = 1`, in each brain's `format` file (none is format 1).
  `MIGRATIONS: &[Migration { to, what, run }]`, empty: `MIGRATIONS[i]` brings format `i + 1` to `i + 2`, steps
  chained and never removed, each working on the files' text. `migrate` runs under the brain's write lock, after a
  copy to `<cache>/kanbrain/backups/<key>/<time>-format-<from>-to-<to>/`, writing the format after each step; from
  `Brain::open_with` and, for every registered brain, `cli::init_all` (`kb update`, the installers). A brain newer
  than `FORMAT` is refused, read or written (`check` in `Store::load`, error `TooNew`); the app leaves such a
  repository out and names it in the status bar. `store::cache_dir_of` is shared with the write lock's path. The
  installers' `--purge` includes `format` and `.format.tmp`.
- Agents first (`core/src/cli/update.rs`): `agents_working` lists the tasks in doing that an agent started
  (`Task::started_by`), in the central brain and every registered repository; `check_no_agent_working` refuses with
  them. `kb update` and the app's update call it before anything else.
- Kanban app (`gui/src/update.rs`, with `core/src/cli/update.rs`): `newer_release` follows the redirect of
  `github.com/singudotdev/kanbrain/releases/latest` with curl (`redirected_version`, `newer`), at start and every
  `CHECK_EVERY` (24 h), unless `KANBRAIN_NO_UPDATE_CHECK` is set; `Board::available` shows **Update to X.Y.Z** in
  the status bar. `U` (`Board::ask_update`) asks (`Confirm::Update`), then `Request::Update`: `install_of` finds the
  install folder (a macOS bundle's `Contents/Resources/install-dir`, which `install.sh` now writes) and on Linux and
  macOS `run_installer` runs `install.sh` with its output captured, then starts the new app and quits; on Windows
  PowerShell waits for the app to exit, runs `install.ps1` and starts it again, leaving an error in
  `%TEMP%\kanbrain-update-failed.txt` for it to show. Installed with cargo, it says to update with cargo.
