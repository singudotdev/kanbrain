Fixes moving a repository to another project on macOS and Windows, where it could stay listed in its old project too.

- `projects::register` finds the repository's earlier registration by folder (`same_dir`), not by path: `init`
  registers the canonical path, which an earlier registration's may not be (`/var` is `/private/var` on macOS,
  Windows prefixes `\\?\`), so a move added a second line instead of replacing the first. `init`'s report of the
  repository's label and its project's other repositories compares the same way.
