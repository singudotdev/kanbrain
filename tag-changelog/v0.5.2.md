An agent working on a task hears the user's comments on it with its next step, not at its next session: a new
Claude Code hook, `kb hook tool`, tells it until it answers. The kanban app asks, on saving a task an agent is working
on, whether to tell the agent what changed. `kb context` adds the new hook to every project that has kanbrain's
hooks, so it arrives with the next session after `kb update`. No API or data change: nothing needs migrating.

- Hooks (`core/src/cli/hook.rs`, `claude.rs`):
  - `kb hook tool` (`HookEvent::Tool`, `PreToolUse` with no matcher, `claude::HOOKS` now 5 entries):
    `hook::tell_of_comments` gives `additionalContext`, never a `permissionDecision`, for each task in doing that an
    agent started (`hook::unanswered`) with a person's comment after the agent's last one (by list order) and not
    before its start (to the second): `kb show N`, then `kb comment N` what it'll do about it. It only reads the
    brain: 1.2 ms here; a 6 ms median and 10 ms max with 500 entries (release build).
  - `kb hook stop` (`hook::uncommented`) counts only the agent's comments since its start: a user's comment no
    longer silences the reminder.
  - `claude::update_hooks`, run by `kb context` on a repository's `.brain`, adds kanbrain's missing hooks to
    `.claude/settings.local.json` only where one of its hooks is already there. Errors never stop the context.
  - `claude::runs` (`init`, `deinit`, `update_hooks`) takes a hook with `kb` written by its path (`/opt/bin/kb …`) or
    with variables set before it (`KANBRAIN_DIR=… kb context`) as kanbrain's; one running `kb` after another command
    (`cd x && kb …`) stays the user's.
- Kanban app (`gui/`):
  - `Mode::Tell` (`Tell { pending: Pending::{Form, Edit}, note }`, `Telling::{Ask, Save, Tell}`): saving the edit
    form, the description or a comment of a task an agent has in doing (`Board::asks_to_tell`) first asks
    `Tell the agent?` (`ui/dialogs/tell.rs`, `Pending::what`). `enter` saves and adds the user's comment
    `Changed the title and tags: <note>` / `Changed the description.` / `Changed a comment.`
    (`Board::tell_agent`; `#N saved; the agent is told`); `ctrl+enter` and **Just save** only save; `esc` goes back to
    the form or editor as it was. A save that changes nothing, a new comment or a task a person runs asks nothing.
    One undo takes the save and the comment back.
  - An agent that finishes the task while the question is open isn't told: `#N saved; not told: no agent is working
    on it now`. A save that stops over `kb`'s change tells nothing; `· changed on disk` marks the form or editor
    waiting behind the question too.
