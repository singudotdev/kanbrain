The kanban app no longer asks what's next when your running task stops: the board shows what's parked and to do.

- Removed "What's next?" (`gui/src/state`): `Board::ask_next`, `next_choices`, `next_new`, `choose_next`,
  `Mode::Next` with `NextPicker` and `NextChoice`, its keys (`key_next`), dialog (`ui/dialogs/pickers.rs`), search
  box (`TextBox::NextSearch`) and scroll handle. `Board::set_status` and a confirmed delete no longer open it.
- Agent section (`cli::init::SECTION`, written by `kb init` and `init --all`): the same words, its two long lines
  wrapped to the others' width; a test checks it still holds `projects::description_scope!`'s text.
