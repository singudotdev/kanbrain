The kanban app remembers the details' width between sessions, per person and computer, outside any brain. No data
format change: nothing to migrate.

- Kanban app (`gui/`):
  - `remembered`: `folder` is `kanbrain-app` in `dirs::state_dir` (`$XDG_STATE_HOME`, `~/.local/state`), else in
    `dirs::data_local_dir` (`~/Library/Application Support`, `AppData\Local`); none in tests unless `remember_in`
    names one. `drawer_width` reads `drawer-width`, none unless finite and positive; `remember_drawer_width` writes
    `.drawer-width.tmp` and renames it over `drawer-width`, making the folder if missing.
  - `ui` (`BrainView`): the width opens as remembered, else `drawer::WIDTH` (420 px). `end_resize` remembers it when
    a drag of the edge ends (button let go, seen or not, or the details closed meanwhile); a double-click remembers
    420. `remembered_width` skips a write of the width last remembered; `remembering` chains each write after the
    last, on the background executor; a failed one says so in the status bar and clears `remembered_width`.
- Installers: `install.sh` and `install.ps1` `--purge` delete `drawer-width` and `.drawer-width.tmp`, then the
  folder once empty; `e2e/install.sh` and `e2e/install.ps1` check it.
- Docs: `docs/decisions/0015-the-app-remembers-in-the-state-folder.md`; `docs/faq.md`, `docs/getting-started.md`
  (what purge deletes), `docs/keybindings.md` (the drag remembered).
