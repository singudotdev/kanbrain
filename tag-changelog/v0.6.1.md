Fixes the debt left before this release: what a one-line field makes of a pasted text with line breaks, which comment
the kanban app deletes when the list changed under its question, a status bar that said one change twice, a field
opened again scrolled where it was left, fish offering `--tag` where no command takes it, and which central files
`kb hook edit` reads and refuses. No API or data change: nothing needs migrating.

- Kanban app (`gui/`):
  - `LineInput::insert` puts a pasted text on one line by `text::editor::on_one_line`: each run of spaces with a line
    break in it is one space, as `kb add` joins a title's lines (`Plan\n\nsteps` is `Plan steps`, it was
    `Plan  steps`); a break at either end of the paste still parts it from the text beside it, but adds no space
    beside a space or the field's end.
  - `Confirm::DeleteComment(Key, Comment)` holds the comment it asks about, not its index (`Board::ask_delete_comment`
    from the comment list and the details' Delete): `y` deletes that comment wherever it is now, or none, saying
    `not deleted: #N's comment was edited or deleted meanwhile`. The dialog shows the comment it'll delete.
  - A save that stops over what `kb` changed, within a second of the read that said `#N's … changed on disk`, takes
    its own field out of that message (`Board::unsay_found`, `edit_changed_but`, `form_changed_but`): `#1's
    description changed meanwhile: save again … · #1's status changed on disk`, not the description twice.
  - A one-line field the board's view didn't draw the time before (a dialog's, opened again) starts at its start
    (`ui::widgets::FieldScrolls`, `next_frame`), not where it was left scrolled.
- Completions (`core/src/cli/completions.rs`): fish offers `--tag` only after `add`, `list` and `report`, the commands
  that take it; it came after `kb tag ID -` too.
- Hooks (`core/src/cli/hook.rs`, `central_owned`): `kb hook edit` refuses a write to a central `.md` it can't read
  (not UTF-8), which `kb` reports as a broken entry, and reads only a top-level `.md` not named as an entry, not every
  file there.
- CI (`.github/plan.sh`): a tree counts as checked only while its run's artifact hasn't expired.
- Docs: ADRs `docs/decisions/0004-the-edit-hook-takes-for-an-entry-what-kb-reads-as-one.md`,
  `0005-ci-runs-a-job-for-what-a-change-touches-and-none-for-a-tree-already-checked.md`,
  `0006-changes-and-releases-are-squashed-and-main-holds-one-commit-per-release.md`; `docs/development.md`'s test
  table.
- Tests: `gui/tests/editor.rs` (pastes mid-text), `gui/tests/state.rs` (deleting the comment asked about, a stop said
  once), `gui/tests/ui.rs` (a field shown again), `core/tests/cli/hook.rs` (an unreadable `.md`),
  `core/tests/cli/completions.rs`; `e2e/agent.sh edit` checks in the transcript that the hook refused each write to
  the brain.
