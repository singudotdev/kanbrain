kanbrain no longer loses an entry file it can't read, nor panics in `kb init --all` on a project named `Central` alone
or with `:` or `/`. The kanban app's form picks tags from a list of those in use, filtered as a tag is typed; its
dropdowns, pickers and menu draw a line between rows, dialogs box their lists, and buttons lose their trailing `…`. A
ctrl+letter no longer runs the letter's action, a dialog on an entry deleted meanwhile closes, and a dragged card is
dropped on its own brain after a reload. Not breaking: `kanbrain-core`'s API is unchanged.

- Data (`core/`):
  - `Store::save` refuses to write an entry over a file of its name that isn't its own (one that didn't parse, a
    sync conflict's): `PATH is there and couldn't be read as #N: fix or move it, then try again`.
  - `Brain::take_id` counts the entry files there (`Store::file_ids`), so a new entry never takes the id of one that
    doesn't parse.
  - `kb init --all` (`rename_unreachable_projects`): a name's `:`, `/` and line breaks become `-`, and candidates run
    to one more than the projects, so a lone `Central` becomes `Central-project` instead of panicking.
  - `kb init`'s message and `docs/agents.md`: the `Stop` hook reminds an agent (additional context), not blocks.
- Kanban app (`gui/`):
  - Form, tags field (`ui::dialogs::form::tags_field`): the tags in use by entries of its kind, with how many use
    each (`Board::form_tags`), those it holds left out, filtered by the tag being typed (`Form::typed_tag`: the word
    the cursor ends, lowercase, without `#`; none with text selected). The first starting with it is highlighted
    (`Form::tag_sel`), only as the text changes and not for a whole tag typed; `↓` `↑` move, `enter` or a click
    (`Board::choose_form_tag`) puts it in place of the word (`Form::put_tag`, then `, `); with none highlighted
    `enter` saves. 6 rows (`FORM_LINK_ROWS`); a line says when the tag typed will be new. It replaces the chips of
    tags in use.
  - Lists (`dropdown::list`, `menu::draw`): a line (`theme::BG`) above every row but the first, inside `ROW_HEIGHT`
    (28), so the "↓ N more" counting holds; rows lose their rounded corners. The palette's section starts keep the
    lighter `BORDER`. `dialogs::list_box` boxes every dialog's list: now also the link picker, comments, which
    project and the palette.
  - Labels: Rename, Move, Remove, Remove project, Link, Answer, Accept with a comment, Reject, Move to project,
    Delete, Edit or delete a comment, without `…`.
  - `Board::key` drops a ctrl+letter outside the editor (`ctrl+d` there discards), where it ran the letter: a
    second `ctrl+d` moved the task to Done, one in the remove dialog deleted its tasks.
  - `after_load` closes a dialog whose entry another program deleted (`Mode::entry`): `closed: #N was deleted
    meanwhile`.
  - A dragged card (`DraggedCard`) carries its brain's folder; `Board::drop_dragged` finds the brain by it.
- Tests and CI: `e2e/upgrade.sh` writes each release's data with `set -e` in effect (it ran left of `||`, where bash
  turns it off); `ci.yml` and `mutants.yml` also run on `develop` (mutants from the last passing run on the pushed
  branch); `docs/development.md` describes the branches: work to `develop` by pull request, `release/vX.Y.Z` from it
  to `main`, then the tag.
