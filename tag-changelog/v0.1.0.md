Project memory for you and your coding agents: tasks, notes and decisions as markdown files next to the code, a CLI
for agents and a kanban board for you, with time tracked automatically. Agents stop to ask you when a choice is
yours, and you answer on the board. Licensed AGPL-3.0-only, with additional terms in `NOTICE`.

- `kb` (`cli/`): the command line agents and scripts use. `init` makes a repository a project (`.brain/`, registered
  in the central brain, a "Project memory" section in `CLAUDE.md` / `AGENTS.md`, Claude Code hooks); `init --all`,
  `deinit`, `context`, `add`, `start` / `park` / `done` / `todo`, `comment`, `ask`, `wait`, `propose`, `accept` /
  `reject`, `describe`, `link` (`REPO#ID` across a project's repositories), `project`, `show`, `search`, `list`,
  `status`, `report`, `update`, `completions`; `--json` on entry commands, `--project NAME` from anywhere.
- Agents and people: comments and status changes record `agent` when a coding agent runs `kb` (`AGENT`, `AI_AGENT`,
  `CLAUDECODE`, `CODEX_*`, `GEMINI_CLI`; `KANBRAIN_AUTHOR` overrides). `ask` parks a task with a question
  (`### TIME (agent, question)`) until a person comments; `wait` polls the files every second (`WAIT_POLL`) and
  prints the answer or the decision's verdict, failing after `WAIT_DEFAULT` (8 min; `--timeout`, `KANBRAIN_WAIT_TIMEOUT`); `propose` creates
  a decision with `- decision: proposed`; `context` lists answered tasks first; `status` counts the waiting ones;
  the `Stop` hook reminds an agent of a task it started without commenting since.
- `kanbrain` (`gui/`, GPUI from Zed 1.23.2): the kanban board (To do · Doing · Parked · Done) or a list, notes,
  decisions, report and calendar tabs; project filter, search and tag filters per tab; details drawer, forms,
  editor, links, right-click menu, command palette (`?`), undo (`u`); **Waiting for you** cards with the agent's
  question, **N waiting for you** (`w`), Accept (`y`) / Reject… (`j`) on decisions; **+ Add project** (`A`) picks a folder in the
  system's dialog and its project from a searchable list. It follows other programs' changes within a second. Given
  arguments, it runs `kb`'s commands.
- `kanbrain-core` (`core/`): the markdown store (atomic writes, an undo journal), brains, projects of several
  repositories, time tracking (one running task per brain), reports, the calendar, the agent API.
- Installers `install.sh` / `install.ps1`: per user, checksum required, `--app cli|gui|both`, uninstall and purge,
  `init --all` after upgrading; the kanban app's launcher with the logo on Linux, macOS (`~/Applications` bundle)
  and Windows (embedded icon, Start Menu).
- Releases: static `kb` on Linux (musl), universal macOS builds, Windows x64; SHA-256 checksums and build provenance
  attestations (`gh attestation verify <file> -R singudotdev/kanbrain`).
