The kanban app shows a scrollbar only while the pointer is over what it scrolls; the agent section `kb init` writes
asks agents to close every turn that changed the repository on the board, with evidence before `done`, and to ask the
user to check what they couldn't. No data format change: nothing to migrate.

- `kanbrain-core` / `kb`:
  - `cli::init` (`SECTION`): a bullet for the end of a turn that changed the repository: the change on a task the
    agent started (created then if skipped), the turn's work commented there, a finished task `done`; a task whose
    work goes through a pull request stays in Doing until every check has passed and it's merged; no `done` without
    its evidence commented first (tests or checks run and their result, a CI run's link, the output, a screenshot);
    what couldn't be checked goes to the user with `ask ID TEXT`, saying what's left and how. `init --all`, run by
    the installers and `kb update`, rewrites it in every registered repository.
  - `api::context` (`write_project`): a repository with no role says `Its role isn't described yet. Before other
    work, describe it from the README and manifests: `kb project notes -` (…)`, as the description's line does.
- Kanban app (`gui/`):
  - `ui::scrollbar`: `Over`, a `HitboxBehavior::Normal` hitbox over the element a bar belongs to (`Over::mark`);
    `bar(scroll, axis, id, over)` draws, and takes presses and the wheel, only while the pointer is over it
    (`Hitbox::should_handle_scroll`, so a key pressed doesn't hide it) or its thumb is held; a `MouseExitEvent`
    hides it until the pointer moves in the window again.
  - `ui::board`: each column marks itself whole, its header too (`column`); the board marks the columns and the strip
    under them (`draw`).
- Dependencies: `serde_json` 1.0.154, `winresource` 0.1.34.
- Docs: `README.md` (an agent's session ends with its evidence), `docs/agents.md`, `docs/keybindings.md`,
  `docs/development.md`.
